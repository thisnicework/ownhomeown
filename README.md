# ⟪공과 주⟫ 공共과 주主 — OWN HOME OWN

서울예술대학교 학사학위 전공심화과정 독립창작프로젝트 전시 **⟪공과 주⟫** 공식 웹 아카이브 및 관람 안내 사이트입니다.

- **일시**: 2026. 11. 25 (수) – 11. 28 (토) `12:00–20:00`
- **장소**: 코스모스 (`경기 안산시 단원구 예술1길 14`)
- **원작 연계**: 2026-2 독립창작프로젝트Ⅱ 선정작 단편영화 〈쓰레기 궁전의 신데렐라〉 확장 전시

## 주요 구성

- **전시개요**: 새로고침할 때마다 새롭게 생성되는 포스터 모티브 블랙 모션그래픽 조형 및 `공共` · `주主` 인터랙티브 타이포그래피
- **전시서문**: 기획의도 전문 및 인쇄 조판 스타일 레이아웃
- **포스터**: 공식 포스터 2종 갤러리 월 딥틱 전시
- **작품**: 코스모스 `주主 1F` / `공共 2F` 인터랙티브 평면도 및 SECTION 1–4 소개
- **크레딧**: `PRODUCTION CREDITS`, `Special Thanks to`, `도움 주신 분들` 분류 필터 및 검색
- **관람안내**: 일정·장소·주소 복사·지도 연동·관람 유의사항 아코디언
- **스폰서**: 주최·주관·제작 지원·공간 협력·원작 연계 기관 안내
